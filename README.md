# Karibotel Domaine Manerinerina

Site vitrine statique du domaine, prêt à être publié avec OpenAI Sites.

## Aperçu local

Servir le dossier `dist` avec un serveur HTTP statique, puis ouvrir `index.html`.

## Contenus

Le site utilise les photos et le logo originaux fournis dans `dist/assets`.

Les textes s’appuient sur les informations publiques de la page Facebook et de ses relais publics. Vérifier les capacités, horaires et prestations avant une mise en ligne publique définitive.
